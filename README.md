# تسکینو (Taskino)

اپلیکیشن ساده و سریع برای نوشتن کارهای روزانه و پیگیری انجام شدنشون — با رابط کاربری فارسی، راست‌به‌چپ و حالت روشن/تاریک.

## امکانات

- افزودن، تیک زدن و حذف تسک‌ها (ذخیره‌شده در `localStorage`)
- حلقه‌ی پیشرفت و کارت‌های آمار برای کل / انجام‌نشده / انجام‌شده
- فیلترهای «همه»، «انجام‌نشده» و «انجام‌شده» همراه با شمارنده
- حالت روشن و تاریک با ذخیره‌ی انتخاب کاربر و احترام به تنظیمات سیستم
- میان‌بر صفحه‌کلید: کلید `/` برای فوکوس سریع روی فیلد افزودن تسک
- اعداد و تاریخ فارسی (شمسی)

## تکنولوژی‌ها

- React 19 + Vite
- Tailwind CSS v4 (با توکن‌های رنگی سفارشی برای حالت روشن/تاریک)
- lucide-react برای آیکون‌ها
- Oxlint برای lint

## اجرا

```bash
npm install
npm run dev      # سرور توسعه
npm run build    # بیلد نسخه‌ی پروداکشن
npm run preview  # پیش‌نمایش بیلد
npm run lint     # بررسی کد
```

## ساختار پروژه

```
src/
├── App.jsx                  # چیدمان اصلی و مدیریت state
├── index.css                # توکن‌های طراحی، انیمیشن‌ها و پایه‌ی حالت تاریک
├── components/
│   ├── TaskForm.jsx         # فرم افزودن تسک
│   ├── TaskItem.jsx         # آیتم لیست با چک‌باکس سفارشی
│   ├── FilterTabs.jsx       # فیلترهای دسته‌بندی
│   ├── StatCard.jsx         # کارت‌های آمار
│   ├── ProgressRing.jsx     # حلقه‌ی درصد پیشرفت
│   ├── EmptyState.jsx       # حالت‌های خالی
│   └── Logo.jsx             # برش لوگو با CSS
├── hooks/useTheme.js        # مدیریت حالت روشن/تاریک
└── lib/format.js            # اعداد و تاریخ فارسی
```
